BioTech R&D Tools

Follow the Steps Below:

  1. Download your csv file with "Results" in the file name from ThermoFisher DataConnect.
  2. Upload the csv results file.
  3. Ensure that the 384 well diagram matches the template used for the run. If it does not, do not continue.
  4. The table labeled "Results Summary" contains Cq/Ct values from the results file organized by target.
  5. The table labeled "Relative Gene Expression Results" allows you to:
    1. Select a gene of interest and house keeping gene for all samples to calculate the relative gene expression for the gene of interest.
    2. Select a reference sample to calculate the gene expression relative to the selected sample. Each sample can have its own reference sample or the same reference sample can be applied to all.
    3. Results can be downloaded via the "Download Excel" button.
    4. For multiple genes of interest, select a gene then download excel file, then repeat for all remaining genes.
  6. (Optional) Clicking the graph button will display the average relative gene expression for each sample as a bar graph.
    1. Green bars are samples that have been selected as a reference sample.
