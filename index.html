BioTech R&D Tools

A set of personal R&D tools used to automate lab work.

Standard Curve (96 Well Plate)

Applies a regression model to a set of standards on a 96 well plate and uses it to interpolate unknowns and expediate SDS-PAGE loading.

Relative Gene Expression (qPCR)

Calculates relative gene expression of treated samples to a reference sample. Currently works with QS7Pro results files only.
